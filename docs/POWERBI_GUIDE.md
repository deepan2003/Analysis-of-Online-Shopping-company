# Power BI build guide

Power BI Desktop is installed on this machine (Microsoft Store build, `PBIDesktopStore.exe`).
Power BI reports cannot be generated by a script, so this guide rebuilds the three
dashboard pages from the prepared MySQL views. Budget: about 20 minutes.

The three reference pages are in `dashboard/screenshots/` and the combined PDF is
`dashboard/Olist_Dashboard.pdf`.

---

## 1. Connect Power BI to the database

The database runs on **127.0.0.1, port 3307**, database `ecommerce_analytics`,
user `root`, password `root` (start it with `tools/start_db.ps1`).

**Option A - MySQL connector (live data)**

1. `Get Data` → `More` → `Database` → `MySQL database` → `Connect`.
2. Server `127.0.0.1:3307`, Database `ecommerce_analytics`.
3. Credentials tab: `Database` → user `root`, password `root`.
4. Select these views (not the raw tables):
   `vw_order_facts`, `vw_monthly_revenue`, `vw_customer_rfm`,
   `vw_rfm_segment_summary`, `vw_cohort_retention`, `vw_delivery_facts`,
   `vw_delivery_by_state`, `vw_delivery_monthly`.
5. Click `Transform Data` → set types on the date columns → `Close & Apply`.

> The MySQL connector needs Oracle's **MySQL Connector/NET 8.0**. If Power BI shows
> "the recommended provider is not installed", install it from
> <https://dev.mysql.com/downloads/connector/net/> or use Option B.

**Option B - CSV exports (no driver required)**

`Get Data` → `Text/CSV` and load the files from `exports\`. Same columns, same names.
This is the fastest path if the connector is missing.

## 2. Data model

Create these relationships (Model view):

| From | To | Cardinality |
| --- | --- | --- |
| `vw_order_facts[customer_unique_id]` | `vw_customer_rfm[customer_unique_id]` | many to one |
| `vw_delivery_facts[order_id]` | `vw_order_facts[order_id]` | one to one |
| `vw_cohort_retention` | none (standalone) | - |

Mark `vw_monthly_revenue[purchase_month]` and `vw_cohort_retention[cohort_month]`
as **text** (they are `YYYY-MM`), and add a `Date` table only if you want time
intelligence; the views already contain the MoM/YoY maths.

---

## 3. DAX measures

Create a `_Measures` table and add:

```dax
Total Revenue = SUM ( vw_order_facts[order_revenue] )

Total Orders = DISTINCTCOUNT ( vw_order_facts[order_id] )

Average Order Value = DIVIDE ( [Total Revenue], [Total Orders] )

Unique Customers = DISTINCTCOUNT ( vw_order_facts[customer_unique_id] )

Revenue MoM % =
VAR CurrentRevenue = [Total Revenue]
VAR PreviousRevenue =
    CALCULATE ( [Total Revenue], DATEADD ( vw_order_facts[purchase_date], -1, MONTH ) )
RETURN DIVIDE ( CurrentRevenue - PreviousRevenue, PreviousRevenue )

Repeat Customers =
CALCULATE (
    COUNTROWS ( vw_customer_rfm ),
    vw_customer_rfm[frequency] > 1
)

Repeat Rate % = DIVIDE ( [Repeat Customers], COUNTROWS ( vw_customer_rfm ) )

At Risk Revenue =
CALCULATE ( [Total Revenue], vw_customer_rfm[rfm_segment] = "At Risk" )

At Risk Revenue % = DIVIDE ( [At Risk Revenue], [Total Revenue] )

Delivered Orders = COUNTROWS ( vw_delivery_facts )

On-Time % = AVERAGE ( vw_delivery_facts[is_on_time] )

Avg Delivery Days = AVERAGE ( vw_delivery_facts[delivery_days] )

Avg Promised Days = AVERAGE ( vw_delivery_facts[estimated_days] )

Avg Delay Days = AVERAGE ( vw_delivery_facts[delay_days] )

Late Orders = CALCULATE ( COUNTROWS ( vw_delivery_facts ), vw_delivery_facts[is_on_time] = 0 )
```

## 4. Page 1 - Executive

| Visual | Fields / setup |
| --- | --- |
| Card x5 | Total Revenue, Total Orders, Average Order Value, Unique Customers, Revenue MoM % |
| Line chart | Axis `vw_monthly_revenue[purchase_month]`, Values `revenue`, secondary line `3-month moving average` |
| Column chart | Axis `purchase_month`, Values `mom_growth_pct`, conditional colour: green if `>= 0` else red |
| Slicer | `purchase_date` between 2017-01-01 and 2018-08-31 (drop the 1-order months) |

Formatting: card labels 10pt grey, values 24pt `#0B2545`; line colour `#0B2545`,
area `#13A89E` at 12% transparency; turn off gridlines on the column chart.

## 5. Page 2 - Customers

| Visual | Fields / setup |
| --- | --- |
| Card x4 | Repeat Rate %, Champions count, At Risk Revenue, Orders per Customer |
| Bar chart | Axis `vw_rfm_segment_summary[rfm_segment]`, Values `customers`, tooltip `pct_of_revenue` |
| Matrix | Rows `vw_cohort_retention[cohort_month]`, Columns `month_index`, Values `retention_pct` |
| Donut | Legend `rfm_segment`, Values `total_revenue` |
| Line chart | Axis `cohort_month`, Values `retention_pct` filtered to `month_index = 1` |

Matrix formatting: conditional background colour on `retention_pct`, font size 7,
sort rows by `cohort_month` ascending, hide month index 0 (it is 100% by definition).

## 6. Page 3 - Logistics

| Visual | Fields / setup |
| --- | --- |
| Card x4 | Delivered Orders, On-Time %, Avg Delivery Days, Late Orders |
| Map | `vw_delivery_by_state[customer_state]` as location, size `delivered_orders`, colour `late_pct` |
| Bar chart | Axis `customer_state`, Values `late_pct`, filter Top N = 10 by `late_pct` |
| Gauge | Value `On-Time %`, target 95%, min 0 max 100 |
| Line chart | Axis `purchase_month`, Values `on_time_pct` |

For the map: select the visual, set **Data category** of `customer_state` to
`State or Province`, and set **Country/Region** to `Brazil` in the visual's
`Format → Map settings` (or add a `country = "Brazil"` column in Power Query).
The `vw_geo_zip` view holds real lat/lng if you prefer a bubble map.

## 7. Export

`File → Export → Export to PDF`, and save the `.pbix` next to it:

```
dashboard/Olist_Dashboard.pbix
dashboard/Olist_Dashboard.pdf
dashboard/screenshots/page1.png ... page3.png
```

The PDF and screenshots in this folder were produced from the HTML renderer
(`dashboard/build_dashboard.py`) that mirrors this exact layout, so the repo is
complete even before the `.pbix` is rebuilt.
